WEBSITE KANGEN UNTUK RIZKA 💗

FILE UTAMA
- index.html: source code lengkap (HTML, CSS, dan JavaScript).
- foto1.jpg sampai foto5.jpg: tambahkan foto kenangan sendiri.
- backsound.mp3: tambahkan audio yang kamu punya izin untuk gunakan.

MENJALANKAN DI VS CODE
1. Ekstrak ZIP.
2. Buka folder website-kangen-rizka melalui VS Code (File > Open Folder).
3. Taruh foto di folder yang sama dengan index.html dan beri nama foto1.jpg, foto2.jpg, foto3.jpg, foto4.jpg, foto5.jpg.
4. Taruh musik bernama backsound.mp3 di folder yang sama.
5. Buka index.html dan klik Go Live (perlu ekstensi Live Server).
6. Buka bagian penghitung hari, pilih tanggal jadian yang benar, lalu klik Hitung. Tanggal tersimpan di browser perangkat tersebut.

FITUR
- Responsive untuk HP dan PC.
- Slideshow foto otomatis dan tombol navigasi.
- Tombol kangen memunculkan pesan dan hujan bunga/hati.
- Tombol tidak kangen kabur saat didekati/disentuh.
- Surat cinta interaktif.
- Penghitung hari/jam/menit/detik dari tanggal jadian yang kamu masukkan.
- Tombol backsound (perlu file backsound.mp3).

HOSTING GRATIS MENGGUNAKAN GITHUB PAGES
1. Buat akun di github.com.
2. Buat repository baru, misalnya website-kangen-rizka.
3. Unggah index.html, semua foto, dan backsound.mp3 ke root repository.
4. Masuk ke Settings > Pages.
5. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
6. Tunggu beberapa saat. GitHub Pages akan menampilkan URL website.
7. Buka URL itu dan uji foto, tombol, surat, tanggal jadian, dan musik.

CATATAN
- Tanggal jadian belum diisi secara default karena harus memakai tanggal kalian yang sebenarnya.
- Musik biasanya tidak bisa autoplay sebelum pengunjung menekan tombol.
- Jangan unggah foto pribadi atau musik yang tidak kamu punya izin untuk bagikan.
- Semua fitur bekerja sebagai website statis, tidak memerlukan backend.
